# Fox App Support

Static support, privacy, and license pages for the iOS app Fox.

- Support: https://trakowskymarcel-pixel.github.io/fox-app-support/
- Privacy: https://trakowskymarcel-pixel.github.io/fox-app-support/privacy.html
- License: https://trakowskymarcel-pixel.github.io/fox-app-support/terms.html

GitHub Actions publishes this site from `main`. The license page points at [Apple’s Standard EULA](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/). App Store Connect should use that standard EULA.
